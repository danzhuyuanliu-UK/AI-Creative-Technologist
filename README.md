# BytePlus Portfolio Site — v4

Static portfolio site with three independently addressable project pages.

## Routes
- `/` — Selected Projects landing page
- `/projects/sacred-intelligence/` — multimodal AI / capture / robotics case study
- `/projects/no-curtain-call/` — real-time performance / tracking / VR case study
- `/projects/1-spitalfields/` — Foster + Partners professional practice case study

## Deployment
Upload the complete folder to one GitHub repository and publish from the repository root using GitHub Pages. No build step is required.

Project pages use relative paths so they work under a GitHub Pages repository subpath.
