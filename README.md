# Sacred Intelligence — project page

A standalone English project page for Zhuyuan Liu. This revision foregrounds the multimodal generative-media system, API orchestration, state/memory and operational testing for AI solution / creative technology applications. No build step or external libraries required.

## Edit

- `index.html`: copy, video IDs and links
- `style.css`: layout, colours and mobile styles
- `script.js`: accessible workflow tabs and video dialog
- `assets/`: web-optimised images extracted from the supplied portfolio
- `Portfolio_Zhuyuan_Liu.pdf`: complete portfolio

Open `index.html` for a local preview, or serve this directory with a static HTTP server. YouTube playback requires an internet connection and may require HTTP/HTTPS; each player has a direct YouTube fallback link.

## Publish

Upload this directory to a static website host. Its index page is the project landing page; no routing configuration is needed. The files are ready for deployment, but this local copy is not a public URL.
