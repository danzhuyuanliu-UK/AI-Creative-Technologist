# BytePlus application site — v3

This package keeps Sacred Intelligence as the primary public case study and adds the full technical project book as secondary evidence.

## Public files
- `index.html` — Sacred Intelligence case study
- `Sacred_Intelligence_Technical_Project_Book.pdf` — 103-page technical documentation
- `Portfolio_Zhuyuan_Liu.pdf` — full portfolio

## Recommended future routes
See `projects/README.md`. No Curtain Call and 1 Spitalfields are deliberately scaffolded but not linked publicly yet because their visual assets are not included in this package.

## Deployment
Upload the full folder to a static host. Keep `index.html`, `style.css`, `script.js`, `assets/`, PDFs, and the `projects/` folder together.
