Selected project / 02 Archway, London · Immersive theatre

No Curtain Call.

Live theatre,
physical interaction & virtual space.

No Curtain Call was an immersive theatre project in Archway, London, combining a physical performance space with a virtual environment. The audience moved between live theatre, physical interaction and digital scenes as part of the same experience.

01 / Project system

One performance,
across two environments.

The project was developed with theatre director Isabel and performer Milo, while I focused on the spatial and technical system. I used Meshroom for photogrammetric reconstruction, inertial motion capture for real-time performance, and Unreal Engine to build the virtual theatre. AprilTag tracking was also tested to connect physical stage elements with the digital environment.

  1. 01 / Reconstruct

    Meshroom

    Photogrammetric reconstruction of physical space and objects.

  2. 02 / Perform

    Inertial motion capture

    Live performer movement transferred into the virtual scene.

  3. 03 / Build

    Unreal Engine

    A real-time virtual theatre connected to the physical performance.

  4. 04 / Track

    AprilTag

    Physical stage elements tested as trackable digital counterparts.

02 / AprilTag tracking test

Physical movement
becomes scene data.

AprilTag tracking was tested as a lightweight way to connect movable stage elements with the digital environment, translating changes in the physical theatre into real-time scene updates.

AprilTag tracking test · physical stage elements connected to the digital environment.

03 / Full system test

A reusable framework
for constrained venues.

The longer-term aim was to develop a reusable performance framework for spatially constrained venues, extending live theatre through digital environments. This short test shows the system in operation.

System test · photogrammetric space, live performance capture and Unreal Engine brought into one performance workflow.
