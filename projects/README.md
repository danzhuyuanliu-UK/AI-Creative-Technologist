# Project routes

Recommended deployment structure for the BytePlus application site.

- `/` — Sacred Intelligence (primary AI / multimodal case study)
- `/projects/no-curtain-call/` — future dedicated real-time interactive performance case study
- `/projects/1-spitalfields/` — future dedicated professional delivery / real-time visualisation case study

Use sibling directories, not separate Git branches. GitHub Pages or another static host can publish all three routes from one deployment branch while keeping direct URLs available for each Project Experience entry.
